# 1.1 创建 repo

```bash
mkdir productname && cd productname
git init -b main
mkdir docs
curl -fsSL https://dotnet-launchpad.vercel.app/TEMPLATE.zh.md -o docs/TEMPLATE.md
```

也可以直接下载：[TEMPLATE.zh.md（中文）](pathname:///TEMPLATE.zh.md) · [TEMPLATE.md（English）](pathname:///TEMPLATE.md)。保存为 repo 中的 `docs/TEMPLATE.md`。

`TEMPLATE.md` 是合成一个 Markdown 文件的完整 Reference，每次发布本站点时重新生成。AI agent 会读取它；走手动路径时，它是一份方便的离线副本。
