# 0.3 准备本机

## Shell

本站的指令以 bash 为准，并带有 `# 注释`。请在 bash 中执行；若使用 zsh，先开启 interactive comments，否则 zsh 会把注释当成额外的参数：

```bash
setopt interactive_comments 2>/dev/null; grep -q interactive_comments ~/.zshrc 2>/dev/null || [ "${SHELL##*/}" != zsh ] || echo 'setopt interactive_comments' >> ~/.zshrc
```

## 工具

```bash
dotnet --list-sdks          # 必须列出 10.0.x SDK；记下确切版本，用于 global.json
docker compose version      # Docker 必须在运行：本地 Seq 日志服务器在其中运行
git --version
gh auth status              # GitHub CLI，用于在步骤 3.2 创建 repo
```

- 如果缺少 .NET 10 SDK，请从 .NET 官方下载页面安装。确切版本会在步骤 1.3 中写入 `global.json`（[Reference 12.3](../reference/code/12-solution-level.mdx#12-3-global-json)）。
- 走 AI 路径时，在终端或 IDE 中准备好你的 coding agent（Claude Code、Cursor 或 GitHub Copilot）。

## 许可证

核心使用两个带商业条款的产品。请在编写代码**之前**，为实际拥有和使用该系统的组织确认许可证（[Reference 8.5](../reference/spec/08-design-rules/05-third-party-licensing.mdx)）：

- **MediatR**（从版本 13 起）：年收入低于 500 万美元且外部融资不超过 1000 万美元的组织可免费使用 Community 许可证。获取 license key。它在步骤 3.1 放进 User Secrets，绝不放进 repo。
- **Seq**：单用户免费，多用户收费。查看当前条款（[Reference 8.9](../reference/spec/08-design-rules/09-logging-rules.mdx)）。

消息附加组件会加入 MassTransit，它有自己的许可证；在该附加组件的页面中说明。
