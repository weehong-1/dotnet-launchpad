# 0.4 准备本机

在[步骤 0.3](./licenses.mdx) 已设定好 shell。检查工具：

```bash
dotnet --list-sdks          # 必须列出 10.0.x SDK；记下确切版本，用于 global.json
docker compose version      # Docker 必须在运行：本地服务和 Testcontainers 需要它
git --version
gh auth status              # GitHub CLI，用于创建 repo 和下载 CI artifact
jq --version                # JSON 解析工具，步骤 0.5 会用到（sudo apt install -y jq）
```

- 如果缺少 .NET 10 SDK，请从 .NET 官方下载页面安装。确切版本会在步骤 1.3 中写入 `global.json`（[Reference 12.3](../reference/code/12-solution-level.mdx#12-3-global-json)）。
- 走 AI 路径时，在终端或 IDE 中准备好你的 coding agent（Claude Code、Cursor 或 GitHub Copilot）。
