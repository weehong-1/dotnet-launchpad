# 0.2 做出项目决策

这些选择每个项目都要重新做。模板为其中一部分提供了代码；其余的只记录你的选择。

| 决策 | 模板代码 | 影响之处 |
| --- | --- | --- |
| API 版本控制（Asp.Versioning，路由如 `/v1/...`） | 无：需要你自己实现 | Api endpoint（[Reference 16.2](../reference/code/16-api.mdx#16-2-endpointextensions-cs)） |
| SonarCloud | [Reference 12.10](../reference/code/12-solution-level.mdx#12-10-github-workflows-ci-yml) 中的 CI job | 步骤 1.3 和 4.1 |
| Qodana | [Reference 12.10](../reference/code/12-solution-level.mdx#12-10-github-workflows-ci-yml) 中的 CI job 和 `qodana.yaml` | 步骤 1.3 和 4.1 |
| 把 artifact 传到 VM | 步骤 4.4 和 4.7 中的手动命令；Tailscale 或其他工具需要你自己搭建 | [Reference 8.21](../reference/spec/08-design-rules/21-deployment.mdx) |
