# 2.2 Application

Application 包含用例，按 CQRS 分为 **Command**（改变状态）和 **Query**（读取状态）。每一个都是只有一个 handler 的 MediatR 请求，每个 handler 都返回 `Result`。

- 我们自己的 `ICommand`、`IQuery` 和 handler 接口包装了 MediatR，让每个用例都有相同的形状。
- 两个 **pipeline behavior** 包在每个 handler 外面运行：先是日志，然后是使用 FluentValidation 的验证。验证只对 Command 运行。
- `DependencyInjection.cs` 用一次调用注册 MediatR、这些 behavior 和每个 validator。

现在不创建任何范例 Command 或 Query；功能会自行加入（[Reference 8.15](../reference/spec/08-design-rules/15-feature-slices-vertical-slice.mdx)）。代码见 [Reference 14](../reference/code/14-application.mdx)。
