# 2.1 Domain

Domain 是 Clean Architecture 的中心，不依赖任何东西。它包含领域驱动设计的基础构件：

- **Entity** 以 ID 判断是否相等；**aggregate root** 是守护一致性边界并发出 **domain event** 的 entity。
- **强类型 ID** 防止在需要客户 ID 的地方传入订单 ID。
- **`Result` 和 `Error`** 以返回值表示预期的业务失败，而不是抛出异常。

现在不创建任何业务 entity；功能会自行加入（[Reference 13.16](../reference/code/13-domain.mdx#13-16-domain-conventions-no-code)）。代码见 [Reference 13](../reference/code/13-domain.mdx)。
