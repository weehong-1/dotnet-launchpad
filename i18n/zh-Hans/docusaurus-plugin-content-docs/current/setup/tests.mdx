# 2.5 测试

四个测试项目将获得：

- 使用 NetArchTest 的**架构测试**。只要代码违反 Clean Architecture 规则，测试就会失败：Domain 引用其他层、handler 没有 sealed，或一个功能使用另一个功能。
- 针对 `Result` 和验证 pipeline 的**单元测试**。
- 一个 **Api 测试**，在内存中启动整个 Api 并调用 `/health`。

它们都不需要 Docker 或授权。代码见 [Reference 18](../reference/code/18-tests.mdx)。
