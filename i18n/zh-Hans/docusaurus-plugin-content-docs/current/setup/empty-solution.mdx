# 1.2 创建项目与引用

Clean Architecture 由项目引用来强制执行：每一层都是独立的项目，一个项目只能使用它所引用的项目。本步骤创建 `.slnx` solution，其中有四个源代码项目和四个测试项目，引用只指向内层：

```text
Api ──► Application ──► Domain
 │           ▲
 └─► Infrastructure
```

Domain 不引用任何项目，Application 只引用 Domain，Infrastructure 实现 Application 所定义的内容。Api 两者都引用，因为它在启动时把所有部分串在一起。[Reference 5](../reference/spec/05-solution-structure.mdx) 展示文件夹结构，[Reference 12.2 表格](../reference/code/12-solution-level.mdx#12-2-directory-packages-props)列出各项引用。
