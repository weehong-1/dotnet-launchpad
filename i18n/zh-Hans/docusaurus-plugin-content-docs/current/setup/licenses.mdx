# B.1 取得 MassTransit 许可证

<AddOnSwitch addon="messaging" />
<StepApplies step="licenses" />

消息附加组件使用 MassTransit，它从版本 9 起采用商业许可证。请在编写代码**之前**，为实际拥有和使用该系统的组织确认许可证（[Reference 8.5](../reference/spec/08-design-rules/05-third-party-licensing.mdx)）：

- 年收入低于 100 万美元的组织*可能*获得全额折扣。提出申请并取得书面答复。
- 如果系统之后移交给另一个组织，该组织需要自己的许可证。

## 让本机可以使用授权

MassTransit v9 从环境变量读取授权：没有授权，Api、Worker 与整合测试都会在启动时失败（[Reference 8.8](../reference/spec/08-design-rules/08-configuration-environments-and-secrets.mdx)）。授权文件放在任何 repo 之外：

```bash
mkdir -p ~/.config/masstransit
cp <下载的授权文件> ~/.config/masstransit/license.txt
PROFILE="$HOME/.${SHELL##*/}rc"
echo 'export MT_LICENSE_PATH="$HOME/.config/masstransit/license.txt"' >> "$PROFILE"
export MT_LICENSE_PATH="$HOME/.config/masstransit/license.txt"
```

在 SIT 和 Production 上，授权改为放在 VM 的环境变量文件中（上线）。
