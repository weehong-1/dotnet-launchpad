# 2.4 Api

Api 是入口。`Program.cs` 把各层串在一起（`AddApplication`、`AddInfrastructure`），并设定每个 HTTP API 都需要的东西：

- **Endpoint** 是 Minimal API 类，每个用例一个，会被自动找到。每个 endpoint 发送一个 Command 或 Query，并把 `Result` 转成响应。
- **错误处理**把失败转成 ProblemDetails 响应。
- 带 Scalar UI 的 **OpenAPI**、**限流**、`/health` endpoint，以及使用 Serilog 写入 Seq 的请求日志。

代码见 [Reference 16](../reference/code/16-api.mdx)。
