根据 [Reference 12](../reference/code/12-solution-level.mdx) 创建每个文件：

1. `Directory.Build.props`、`Directory.Packages.props`、`global.json`、`.editorconfig`、`docker-compose.yml` 和 `BannedSymbols.txt`（12.1 至 12.6）。将 `global.json` 设为步骤 0.4 中的 SDK 版本。在 `Directory.Packages.props` 中填入最新的稳定版本。
2. `deploy/systemd/`、`deploy/nginx/` 和 `deploy/env/`（12.7 至 12.9）。
3. `.github/workflows/ci.yml`（12.10），如果在步骤 0.2 中选择了 SonarCloud 和 Qodana，再加上它们的 job。
4. 按照 [12.2 表格](../reference/code/12-solution-level.mdx#12-2-directory-packages-props)为每个项目加入 NuGet package，不指定版本：`dotnet add src/ProductName.Domain package MediatR.Contracts`，依此类推。
5. 步骤 1.2 的指令已删除模板范例、模板加入的带版本包引用，并把 Worker 的 `Program.cs` 换成最小版本。最小的 `Program.cs` 保留到步骤 2.4 与 2.5 再取代。

```bash
dotnet build
docker compose config --quiet && echo "compose ok"
```
