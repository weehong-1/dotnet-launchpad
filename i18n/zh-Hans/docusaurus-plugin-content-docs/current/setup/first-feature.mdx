# 4.1 准备开始功能开发

Setup Flow 到此结束：核心 Skeleton Solution 已经运行，还没有任何业务功能。

## 先加入附加组件

大多数后端在第一个功能之前都需要一些[附加组件](./addons.mdx)：存储 aggregate 的数据库、把工作交给后台的消息、登录。趁还没有功能依赖核心的形状，现在就加入它们。上线通常放在最后。

## 然后是功能

从现在起，每个用例都是一个 feature slice（[Reference 8.15](../reference/spec/08-design-rules/15-feature-slices-vertical-slice.mdx)）：一个 Command 或 Query 及其 handler 和 validator、一个 endpoint，以及测试，每个用例放在一个文件夹中。开发功能是日常的项目工作，不属于 setup。

写第一个用例时，填写尖括号中的内容，然后把这段提示词交给 agent，每个用例一次：

<PromptFeatureSlice />

把它放在找得到的地方：加到 agent 指令文件（步骤 1.1）的通用规则下方，或把本页加入书签。

想看各部分如何串起来，请阅读[附录 A 的演示](../reference/appendix/a-demo-code.mdx)。它假定已加入 PostgreSQL、消息和身份验证附加组件，只供阅读：不要复制进项目。
