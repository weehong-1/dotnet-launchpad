# 8.5 第三方授权 \{#8-5-third-party-licensing\}

MediatR（13 版起）与 MassTransit（v9 起）都已改为商业授权，每个项目启动前都要确认授权：

- **MediatR**：年营收低于 500 万美元、且外部融资未超过 1000 万美元的机构，可使用免费 Community 授权。授权资格以**实际拥有与使用该系统的机构**为准。
- **MassTransit v9**：年营收低于 100 万美元的机构**可能**获得全额折扣，但官方用词为“可能”，需申请确认。若系统日后交由其他机构维护，该机构需自行取得授权。
- **MassTransit v8**：仍为 Apache 2.0 免费授权，但官方维护于 2026 年底结束，新项目不建议采用。
- **FluentAssertions**：自 8 版起商业用途需付费授权。英文 guide 使用 FluentAssertions 8，本模板不引入，测试以 xUnit 内建的 `Assert` 为主；若需要更易读的断言，可考虑开源的 Shouldly。
