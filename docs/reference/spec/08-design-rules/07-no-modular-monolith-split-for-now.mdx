# 8.7 No modular monolith split for now \{#8-7-no-modular-monolith-split-for-now\}

However many features there are, the default is feature slices inside each layer (see [8.15](./15-feature-slices-vertical-slice.mdx)) rather than splitting into many projects. Consider a modular monolith only when the team grows or modules need independent deployment.
