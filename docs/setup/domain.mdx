# 2.1 Domain

Domain is the centre of Clean Architecture and depends on nothing. It holds the building blocks for Domain-Driven Design:

- **Entities** are equal by ID; **aggregate roots** are the entities that guard a consistency boundary and raise **domain events**.
- **Strongly typed IDs** stop an order ID from being passed where a customer ID is expected.
- **`Result` and `Error`** return expected business failures instead of throwing them.

No business entity is created now; features add their own ([Reference 13.16](../reference/code/13-domain.mdx#13-16-domain-conventions-no-code)). The code is in [Reference 13](../reference/code/13-domain.mdx).
