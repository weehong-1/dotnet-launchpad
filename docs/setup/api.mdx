# 2.4 Api and the first migration

The Api is the HTTP entry point: endpoints, authentication, permissions, rate limiting, error handling, OpenAPI and health checks. This step also creates the first migration. The code is in [Reference 16](../reference/code/16-api.mdx).

:::note
The prompt's runtime checks (b) to (d) need local services and secrets, so they are checked in steps 3.1 and 3.2. Here, check that it builds and that the migration is right.
:::
