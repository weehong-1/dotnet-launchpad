# 2.4 Api

The Api is the entry point. `Program.cs` wires the layers together (`AddApplication`, `AddInfrastructure`) and sets up what every HTTP API needs:

- **Endpoints** are Minimal API classes, one per use case, found automatically. Each one sends a Command or Query and turns the `Result` into a response.
- **Error handling** turns failures into ProblemDetails responses.
- **OpenAPI** with the Scalar UI, **rate limiting**, a `/health` endpoint, and request logging with Serilog to Seq.

The code is in [Reference 16](../reference/code/16-api.mdx).
