# 4.6 Production: first-time VM setup

Prepare the Production Ubuntu VM once, following [Reference 8.21](../reference/spec/08-design-rules/21-deployment.mdx). Production gets its **own** database, broker, Seq API key and secrets; nothing is shared with SIT ([Reference 8.8](../reference/spec/08-design-rules/08-configuration-environments-and-secrets.mdx)).

Before you start, have these ready: an x86-64 VM running Ubuntu 24.04 LTS (CI publishes linux-x64 artifacts, and these commands are written for 24.04) with SSH access, a DNS name for the Api pointing at it, and the backing services from [step 4.5](./prod-services.mdx).

## Backups

Turn on daily automatic database backups and keep them as long as the project requires. Rehearse a restore now, not during an incident. With a managed cloud database, enable its automatic backup and point in time restore.
