# 1.2 Create the empty solution and project references

This step creates the `.slnx` solution, every project in [Reference 5](../reference/spec/05-solution-structure.mdx), and the project references from the [Reference 12.2 table](../reference/code/12-solution-level.mdx#12-2-directory-packages-props).

<Tabs groupId="route" queryString>
<TabItem value="script" label="Script" default>

<ScaffoldCommand />

Run it inside the repository folder from step 1.1. This one command does **steps 1.2 to 2.6**: it creates every project and reference, fills `Directory.Packages.props` with the latest stable versions, writes all solution level files and every Boilerplate file from this Reference (leaving out what your Project Settings exclude), builds the solution, and creates the `InitialCreate` migration. Add `--test` to also run `dotnet test` (Docker must be running).

The script is generated from the Reference each time the site is published, so it always matches the code shown here. [Read it](pathname:///scaffold.sh) before you run it.

Afterwards, go through the Done Conditions of steps 1.2 to 2.6 to check the result.
