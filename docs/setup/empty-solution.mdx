# 1.2 Create the projects and references

Clean Architecture is enforced by project references: each layer is its own project, and a project can only use the projects it references. This step creates the `.slnx` solution with four source projects and four test projects, and references that point inwards only:

```text
Api ──► Application ──► Domain
 │           ▲
 └─► Infrastructure
```

Domain references nothing, Application references only Domain, and Infrastructure implements what Application defines. The Api references both, because it wires everything together at startup. [Reference 5](../reference/spec/05-solution-structure.mdx) shows the folder layout and the [Reference 12.2 table](../reference/code/12-solution-level.mdx#12-2-directory-packages-props) lists the references.
