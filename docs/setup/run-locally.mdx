# 3.1 Run the Api

Start Seq, the local log server, and check that it is up:

```bash
docker compose up -d
docker compose ps
```

Seq is at [http://localhost:5341](http://localhost:5341). The local settings in `docker-compose.yml` and `appsettings.Development.json` are defaults, not secrets ([Reference 8.8](../reference/spec/08-design-rules/08-configuration-environments-and-secrets.mdx)).

Put the MediatR license key from step 0.3 into User Secrets, never into the repository:

<FlagScope core>

```bash
dotnet user-secrets set "MediatR:LicenseKey" "<key>" --project src/ProductName.Api
```

</FlagScope>

Start the Api:

<FlagScope core>

```bash
dotnet run --project src/ProductName.Api
```

</FlagScope>

The template picks a random port for each project. In another terminal, read the Api's URL from the `http` profile in `Properties/launchSettings.json` and check it:

```bash
API=$(awk -F'"' '/"http": *\{/{p=1} p&&/"applicationUrl"/{print $4; exit}' src/ProductName.Api/Properties/launchSettings.json)
echo $API                   # the same URL as "Now listening on"
curl -i $API/health         # 200 and Healthy
curl -i $API/openapi/v1.json
```

Open `$API/scalar` in a browser for the API documentation, and Seq at [http://localhost:5341](http://localhost:5341) to see the request log entries arrive.
