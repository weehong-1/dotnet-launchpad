# 1.1 Create the repository

```bash
mkdir productname && cd productname
git init -b main
mkdir docs
curl -fsSL https://dotnet-launchpad.vercel.app/TEMPLATE.md -o docs/TEMPLATE.md
```

Download it directly: [TEMPLATE.md (English)](pathname:///TEMPLATE.md) · [TEMPLATE.zh.md (中文)](pathname:///TEMPLATE.zh.md). Save it as `docs/TEMPLATE.md` in the repository.

`TEMPLATE.md` is the whole Reference in one Markdown file, rebuilt every time this site is published. The AI agent reads it; on the manual route it is a handy offline copy.
