# 2.5 Tests

The four test projects get:

- **Architecture tests** with NetArchTest. They fail the build's tests whenever code breaks the Clean Architecture rules: Domain referencing another layer, a handler that is not sealed, or one feature using another.
- **Unit tests** for `Result` and for the validation pipeline.
- **An Api test** that starts the whole Api in memory and calls `/health`.

None of them needs Docker or a license. The code is in [Reference 18](../reference/code/18-tests.mdx).
