# 1.3 Add the solution level files

These files sit at the repository root and apply to every project:

- shared build settings, with warnings treated as errors
- one central list of NuGet versions
- the SDK version
- code style
- a `docker-compose.yml` that runs Seq, the local log server

[Reference 12](../reference/code/12-solution-level.mdx) explains each one.

```bash
dotnet build
docker compose config --quiet && echo "compose ok"
```
