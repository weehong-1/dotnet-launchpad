<TabItem value="manual" label="Manual">

Create each file from [Reference 12](../reference/code/12-solution-level.mdx):

1. `Directory.Build.props`, `Directory.Packages.props`, `global.json`, `.editorconfig`, `docker-compose.yml` and `BannedSymbols.txt` (12.1 to 12.6). Set `global.json` to the SDK version from step 0.4. Fill in `Directory.Packages.props` with the latest stable versions.
2. `deploy/systemd/`, `deploy/nginx/` and `deploy/env/` (12.7 to 12.9).
3. `.github/workflows/ci.yml` (12.10), plus the SonarCloud and Qodana jobs if you chose them in step 0.2.
4. Add NuGet packages per project from the [12.2 table](../reference/code/12-solution-level.mdx#12-2-directory-packages-props), with no version: `dotnet add src/ProductName.Domain package MediatR.Contracts`, and so on.
5. The step 1.2 commands already removed the template samples, the templates' versioned package references and replaced the Worker's `Program.cs` with a minimal one. The minimal `Program.cs` files stay until steps 2.4 and 2.5 replace them.

```bash
dotnet build
docker compose config --quiet && echo "compose ok"
```
