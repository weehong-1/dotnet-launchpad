# F.2 SIT: backing services

<StepApplies step="sit-services" />

SIT needs its own Seq, plus PostgreSQL and RabbitMQ with those add-ons, shared with nothing else ([Reference 2](../reference/spec/02-technical-baseline.mdx), [8.8](../reference/spec/08-design-rules/08-configuration-environments-and-secrets.mdx)). This step creates them: PostgreSQL and RabbitMQ as managed services, Seq on its own small VM. Create the SIT VM of step F.3 first (x86-64, Ubuntu 24.04 LTS) so you know the IP address the backing services must allow.

<BackingServices env="SIT" />

Keep every password, URL and API key from this step in your password manager. They go into the env files in step F.3.
