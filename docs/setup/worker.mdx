# 2.5 Worker

<StepApplies step="worker" flag="worker" />

The Worker hosts consumers and delivers the Outbox. It holds no business logic: every consumer turns a message into a Command. The code is in [Reference 17](../reference/code/17-worker-optional.mdx).

<TabItem value="manual" label="Manual">

1. Copy the four settings files from [Reference 16.12](../reference/code/16-api.mdx#16-12-appsettings-files-4) and change them as [Reference 17.1](../reference/code/17-worker-optional.mdx#17-1-appsettings-files-4) lists: remove `Cors`, `OpenApi`, `Migrations`, `Authentication` and `RateLimiting`, set `Serilog:Properties:Application` to `ProductName.Worker`, and set the log path to `/var/log/productname/worker/log-.json`.
2. Replace `Program.cs` with [Reference 17.2](../reference/code/17-worker-optional.mdx#17-2-program-cs).
3. Check that `Properties/launchSettings.json` sets `DOTNET_ENVIRONMENT` to `Development`.

Finish by creating this project's `GlobalUsings.cs` from [Reference 11.3](../reference/code/11-file-overview.mdx#11-3-globalusings-cs-per-project), then build:

```bash
dotnet build
```
