# 2.3 Infrastructure

Infrastructure implements the abstractions Application defines: databases, message brokers, current user and other technical services. In the core it is almost empty: `AddInfrastructure` registers `TimeProvider`, health checks and resilience for outbound HTTP calls. The [Add-ons](./addons.mdx) fill it in: PostgreSQL adds EF Core, Messaging adds MassTransit, Authentication adds the current user. The code is in [Reference 15](../reference/code/15-infrastructure.mdx).

<Tabs groupId="route" queryString>
<TabItem value="manual" label="Manual" default>

Infrastructure needs the ASP.NET Core shared framework for the HTTP context accessor. Add it to the project file:

```xml
<!-- src/ProductName.Infrastructure/ProductName.Infrastructure.csproj -->
<ItemGroup>
  <FrameworkReference Include="Microsoft.AspNetCore.App" />
</ItemGroup>
```

Then create these files in `src/ProductName.Infrastructure/`:

<LayerFiles project="Infrastructure" />

```bash
dotnet build
```
