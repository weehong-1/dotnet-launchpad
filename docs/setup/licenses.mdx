# B.1 Get the MassTransit license

<AddOnSwitch addon="messaging" />
<StepApplies step="licenses" />

The Messaging add-on uses MassTransit, which has a commercial license from version 9. Confirm it **before** writing code, for the organisation that will actually own and use the system ([Reference 8.5](../reference/spec/08-design-rules/05-third-party-licensing.mdx)):

- Organisations under USD 1 million annual revenue *may* get a full discount. Apply and get the answer in writing.
- If the system is later handed to another organisation, that organisation needs its own license.

## Make the license available locally

MassTransit v9 reads its license from the environment: without it the Api, the Worker and the integration tests fail at startup ([Reference 8.8](../reference/spec/08-design-rules/08-configuration-environments-and-secrets.mdx)). Keep the file outside any repository:

```bash
mkdir -p ~/.config/masstransit
cp <downloaded license file> ~/.config/masstransit/license.txt
PROFILE="$HOME/.${SHELL##*/}rc"
echo 'export MT_LICENSE_PATH="$HOME/.config/masstransit/license.txt"' >> "$PROFILE"
export MT_LICENSE_PATH="$HOME/.config/masstransit/license.txt"
```

On SIT and Production the license goes into the VM's env files instead (Go live).
